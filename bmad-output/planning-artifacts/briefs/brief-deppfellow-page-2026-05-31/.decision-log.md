# Decision Log: Product Brief

## 2026-05-31 — Initial Creation

**Intent:** Create
**Source:** PROJECT.md, REQUIREMENTS.md, ROADMAP.md, research docs, user input

### Key Decisions

1. **Reframed from "portfolio and blog" to "personal journal with sharing"**
   - User clarified: "The only purpose of the project is act as my journaling places"
   - Impact: Threaded log becomes central, not a feature

2. **Priority ordering established**
   - #1: Writing experience (author's workflow)
   - #2: Performance (fast for author and visitors)
   - **Hard constraints:** 100ms target, 200ms hard cap, minimal-to-zero JS bundle
   - Impact: All technical decisions serve these two priorities; performance constraints are non-negotiable

3. **Scope boundaries confirmed**
   - v1 includes: Markdown rendering, threaded log, single-user auth, split-pane editor, dark-first design, SSG, search, Docker
   - v1 excludes: Multi-user, comments, real-time collab, full-text DB search, mobile app, OAuth, admin dashboard, i18n

4. **Tech stack confirmed as boring-by-design**
   - Go+Astro+SQLite chosen for maintainability over novelty
   - 5-year horizon: should still be running with minimal intervention
