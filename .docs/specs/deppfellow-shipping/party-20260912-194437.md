## Round 1 — findings (blind)

Three lenses convened: Architect, Senior Engineer, Product Owner (greenfield). All three requested round 2. Consolidated finding set below; source lenses and severities retained for disposition tracing. (Round-2 de-identification assigns fresh F-numbers F1..F15 in the same order.)

### Blockers
- **F1 (Architect/SE/PO, 0.90/0.95/0.97)** — FAB contradiction: the FAB needs script on pages the CONSTRAINT, REQ-14, D-16 and the script-count Testing seam declare script-free. SPEC-AC-01 is unsatisfiable as written; T6 cannot be built without a decision. Attacks: REQ-07, Constraint, Implementation Decisions, D-16, SPEC-AC-01.
- **F2 (Architect 0.85 / SE 0.90 / PO 0.90)** — repository_dispatch across repos needs a token stored as a wiki-repo secret, contradicting ADR-0007's "no secrets"; the wiki-side trigger workflow is owned by no ticket, so SPEC-AC-07 (the central publish loop) cannot fire. Attacks: REQ-18, D-06, ADR-0007, T12.

### Majors
- **F3 (Architect 0.85 / SE blocker 0.95 / PO 0.92)** — ADR-0005 V1 scope (wikilinks resolved, images, footnotes, task lists, inline tags) is dropped from REQ-04; no wikilink-resolution slice exists, and REQ-21/T13 (agent graph neighbors, raw-markdown URLs) depends on that pass. A compliant reading page can violate a settled ADR. Attacks: REQ-04, T5, ADR-0005, REQ-21.
- **F4 (Architect 0.75 / SE 0.90 / PO 0.80)** — Tag pages are orphaned: D-04 makes reading-page tags plain text, no surface links to /tags/<tag>, contradicting ADR-0008's chip-linking consequence. Build output no visitor can reach. Attacks: REQ-12, D-04, ADR-0008.
- **F5 (Architect 0.75 / PO 0.85)** — Deploy gate deadlocks shipping: CI clones the real (empty) wiki, so every build fails before deploy; the Accepted Risk's "builds against fixtures" is false for CI; no bootstrap/seeding ticket; site-repo-only pushes also blocked. Attacks: REQ-19, T12, Accepted Risk.
- **F6 (Architect 0.80)** — Repo rename to deppfellow/deppfellow.github.io and enabling Pages-from-Actions are unowned human GitHub-settings actions; renaming late breaks every baked absolute URL (REQ-20, ADR-0011). Attacks: REQ-20, T12, ADR-0011.
- **F7 (Architect 0.70 / PO 0.70 / SE mixed)** — description vs the legacy ## Goal summary precedence undefined: Projects rows, ledes, RSS summaries when a note has both or only one of description / ## Goal. Today's loader derives summary from ## Goal; the split is not decided. Attacks: T1, REQ-02, REQ-10, REQ-15.
- **F8 (Architect 0.70 / SE 0.80 / PO 0.80)** — /projects/<slug> and /logs/<date> get no detail page; REQ-03..08 are Articles-only; REQ-11 log prev/next has no page to live on; RSS links for Projects go where? ADR-0003 routes 404 on click. Attacks: REQ-08/REQ-11/REQ-15, ADR-0003.
- **F9 (Architect 0.60 / SE 0.85 / PO 0.70)** — Deploy gate grep checks are hollow: grep for "rss.xml"/"search" passes on text mentions, and a loader Article-count isn't observable from shell — either an emitted artifact or a loader throw. Attacks: REQ-19, Implementation Decisions, Testing seam.

### Minors
- **F10 (all)** — /search has no entry point; D-08 moved it off the header, nothing links to it; ADR-0009's one-click-search 404 rationale silently broke. Attacks: REQ-13/REQ-14, rule-band definition.
- **F11 (Architect)** — Sitemap in ADR-0011 consequences has no REQ and no non-goal; governing-reference trail broken.
- **F12 (SE)** — description required vs optional failure semantics undefined (per-note vs whole-build; hard-throw like `created` or fallback).
- **F13 (SE)** — "HEAD" ref undefined; repository_dispatch carries no branch; pin the checkout ref (default branch).
